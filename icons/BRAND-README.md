# Quarchive identity kit — provisional

**Pending founder review:** treat every file here as provisional, not as approved brand material.

Style source: <https://brand.letsimpl.fyi> (black and white only, no colour, gradients or shadows). The mark is drawn on a 256 × 256 grid with `stroke-width="6"`, black `#000000` on transparent; the app icons place it on a white square.

Files:

- `favicon.svg` — 24×24 output, `viewBox="0 0 256 256"`, black on transparent.
- `logo-mark.svg` — same geometry, 64×64 output, black on transparent.
- `logo-mark-inverse.svg` — same geometry, 64×64 output, white on transparent, for dark backgrounds.
- `icon-192.png` — 192×192 PWA icon, black mark on white, square corners.
- `icon-512.png` — 512×512 PWA icon, same treatment.
- `icon-512-maskable.png` — 512×512 maskable icon, mark held inside the central 80 % safe zone.
- `apple-touch-icon.png` — 180×180, same treatment.
- `og-image.png` — 1200×630, mark plus the live-text wordmark `quarchive` set in Atkinson Hyperlegible Mono (same family as `../brand/fonts/atkinson-hyperlegible-mono-latin.woff2`). No tagline.

The mark is the founder's own drawing, made in VectorCraft. Its control points were later normalised so every mirrored pair is exact about `x = 128`; the tassel is intentionally one-sided and remains the only asymmetry. SVGs are the source of truth — the PNGs are rendered from them, and the Open Graph wordmark is carried over from the previous card so the type is unchanged.
