# Quarchive identity kit — provisional

Generated by an AI subagent at the user's explicit request. **Pending founder review:** treat every file here as provisional, not as approved brand material.

Style source: <https://brand.letsimpl.fyi> (black and white only, square corners, 24-grid monoline pictogram, `stroke-width: 2`, square caps, miter joins, no colour, gradients or shadows).

Files:

- `favicon.svg` — 24×24 viewBox, black mark on transparent.
- `logo-mark.svg` — same geometry, 64×64 output, black on transparent.
- `logo-mark-inverse.svg` — same geometry, 64×64 output, page-white on transparent, for dark backgrounds.
- `icon-192.png` — 192×192 PWA icon, black mark on white square, square corners.
- `icon-512.png` — 512×512 PWA icon, same treatment.
- `icon-512-maskable.png` — 512×512 maskable icon, mark held inside the central 80% safe zone.
- `apple-touch-icon.png` — 180×180, same treatment.
- `og-image.png` — 1200×630, small mark plus live-text wordmark `quarchive` set in Atkinson Hyperlegible Mono (same family as `../brand/fonts/atkinson-hyperlegible-mono-latin.woff2`). No tagline.

The mark was drawn as real vector paths in VectorCraft and exported to SVG and PNG; the Open Graph wordmark was set as live type before rasterising.
